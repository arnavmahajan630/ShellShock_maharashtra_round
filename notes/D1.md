Numbers are read from `ml.contracts.params`. The probe bank is `ml/data/probes.json` (14 probes, not edited).

## How a diagnosis should call it (for S2)

```python
posterior = prior(model.posterior_dict(p_code), active, masked=masked_classes)
posterior = update(posterior, answer, options=item["options"], correct=item["correct"], belief=item["belief"])
posterior = apply_text(posterior, reader_probs, unsure=(reader_status == "unsure"))
diagnosis = decide(posterior, best_probe=make_best_probe(probes_asked), probes_asked=probes_asked, ...)
```

`active` is `{class: P(active)}` for misconceptions. Omit `options` only for a free numeric prediction; the answer is mapped onto `{correct, each distinct belief value, "other"}`. `make_best_probe` rereads the same `asked` list on every call, so appending an id drops that probe next time.

## Still faked

Nothing in this layer is a stand-in. The probabilities are the hand-set assumptions in `params.py`, which is what 03 §6.2 requires; they are not estimated from learners. There is no learner store here: a misconception missing from `active` uses `POPULATION_PRIOR`.

## Decisions where the plans are silent

1. **Not diagnostic** when the belief entry is missing, equal to the correct answer, or not one of the options. The plan's rule is "defined and ≠ correct"; the option check is so `p_b` has somewhere to sit. Every probe belief is an option.
2. **Floor, then one renormalise.** With many options the spread can be lifted to `PROB_FLOOR` and the division can put it back slightly under the floor. The test checks that formula (10 options, slip row).
3. **A diagnostic item with no third option** drops the remainder (nowhere to spread it) and the renormalise rescales. Every probe has three options.
4. **Free answers** are compared as strings, so `5` and `"5"` are the same option. Order is correct, then belief values in map order, then `"other"`. `"other"` is the bucket name from 03 §6.2; it is not in `params.py`.
5. **Top-3 ties** break by `LABELS` order, the same order `decide.ranked` uses. **EIG ties** keep the earlier probe in the bank.
6. **Fallback** uses `twin_set_of` on the top two classes and the id `P_<set>_a`. T6 asks `P_T6_a`, not the reused `P_T2_a`. It runs only when no unasked probe's belief map meets the top 3, and it is still dropped if that probe was asked or its EIG is under 0.10.
7. **`apply_text`**: a class the reader does not mention gets `P_text = 0`. `CORRECT_REASON` is ignored; it is not a Bayes label. `unsure=True` copies the 19 probabilities and does not renormalise. A class already at 0 stays at 0, including masked classes.
8. **`make_best_probe`** fixes the probe list at construction and rereads `asked` on each call.
