## Built

- `tests/B2/test_dsa_bank.py`.

Q17 started from the W0 fixture, with an adversarial tag on `n = 1`. The fixture was not edited.

## Decisions

1. **Coverage ids are training problems and must list the class.** D01 on Q01, Q08, Q15; D02 on Q03, Q05; D03 on Q06, Q07, Q10, Q11; D04 on Q06, Q07; D05–D07 on Q17 and Q18; D08 on Q14 and Q15. A class may also appear on other problems (Q04 and Q12 also expose D01).
2. **Q13 forbids `strlen`** and the prompt says so. The correct variants count the terminator themselves.
3. **Q16, Q17 and Q18 say "use recursion"** and every test carries `max_depth_le`. All three variants of each are recursive, so the D05–D07 operators have a site.
4. **In-place problems expect `array0`.** Q06 and Q07 also carry `one_pass`, a single pass of that sort, for `r_eq_one_pass` later. The checker checks that the string is present. It does not run it.
5. **Q09 exposes OTHER**, same rule as P16 in the main bank. Duplicates count: two equal maxima make that value the second largest too.
6. **Search variants that walk backwards** are correct on these tests because each target value occurs once, so the first index and the last index are the same.
7. **Empty array and empty string** are real tests (`array_sum_rec` of n = 0, `str_length` and `is_palindrome` of `""`). Both backends accept them.
