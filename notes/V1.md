# V1 — Simulated learners: resolution and exam

These learners are simulations. They are not real students. Every table says so.

## Built

- `ml/eval/sim_learners.py`: E10. Five simulated types, three policies, budget of 4 follow-ups + 1 ghost. `g_sim`, `s_sim`, `p_b_sim` drawn per learner from ±50% around the engine values in `ml.contracts.params`.
- `ml/eval/sim_exam.py`: E14. 17-class hidden profiles, three exam policies, 5 coding + 5 trace. Adaptive choice is `select_next`. Updates go through `update_p` and `next_state`.
- `ml/eval/e10_resolution.py`, `ml/eval/e14_exam.py`: write the card, the markdown table, and the plot.
- `ml/eval/_v1_stats.py`: mean and 95% Student-t interval across seeds.
- `ml/eval/_v1_confusion.py`: E1 out-of-fold confusion for E14, plus the stand-in behind `confusion="stand-in"`.
- `tests/V1/`.
- Outputs: `ml/eval/e10_card.json`, `e10_table.md`, `e10_bars.png`, `e14_card.json`, `e14_table.md`, `e14_curve.png`.

Seeds: E10 `1010`, E14 `1414`, via `numpy.random.SeedSequence`. 2,000 learners per cell per seed, 20 seeds. The interval is the uncertainty of that Monte Carlo mean. It is not a confidence interval for real learners.

## E10 (simulated)

Pattern-copier false-resolve: ours 0.106 [0.103, 0.109], naive 0.968 [0.967, 0.970]. Ratio 0.109. The "ours ≤ ½ × naive" bar is met on this simulation.

`ours` false-not-yet on truly_fixed is 0.182 [0.176, 0.188]. Naive is 0. The ghost return relapses a simulated learner who slips. That cost is real in this setup. Naive never asks the ghost, so it almost never fails to resolve someone who is truly inactive, and it false-resolves pattern-copiers at 0.968.

Forgetful, still simulated: naive false-resolve is 1.000 because the relapse is rolled in before the ghost and naive does not give a ghost. Ours is 0.477 [0.468, 0.486]. The ghost cuts it. It does not cut it in half.

Rows are P(argmax | dataset label), not the soft-label counts in `cards/E01_confusion.png`, which would hide an acceptable alternate by moving it onto the diagonal. Mean diagonal over the 17 misconceptions is 0.710. The loader reads `_ea_cache/oof.npz` and the model meta and refuses to train if the data hash does not match. E-a files were not edited.
- Skill noise. §9.3b names it and gives no range. Each simulated learner draws a multiplier uniform on [0.85, 1.0].
- Entering P for a STABLE class at exam start. The plan only says STABLE means P < 0.15. The sim uses 0.12, which is under `STABLE_P` and above `MASTERED_P`.

## Decisions where the plans are silent

1. **E10 is one misconception.** The item-response rows do not depend on the class id. The episode is the M01-shaped update (population prior, one signature failure, one intervention, then the policy). Running all 17 classes would repeat the same arithmetic.
2. **`g_sim` is the slow learner's active rate.** The behaviour cell for `slow` is empty. While active (after the first intervention only), P(correct) is the engine `g` times a ±50% draw. After the second intervention they answer as inactive (`1 - s_sim`). Pattern-copier code rates stay the stated 0.9 / 0.5 / 0.5. Lucky code stays 0.35. Lucky trap and MCQ are uniform on 3 options.
3. **Pattern-copier trap and concept MCQ.** "Belief answer with `p_b_sim`" plus the §6.2 split of the remainder: P(correct) = `(1 - p_b_sim) * Q_CORRECT`.
4. **Ghost behaviour for a pattern-copier** is the transfer rate 0.5. The plan does not name a ghost rate. Only `ours` administers the ghost. Naive and 4-check stop inside the 4 follow-ups.
5. **4-check model gate.** `p_k < 0.25` is true exactly when a new coding task passed, which is the collapse the plan describes. The policy does not read `update_p`.
6. **Declared resolved** means the final state is STABLE or MASTERED (`ours`), or the policy's own rule fired (naive, 4-check). A failed ghost that returns RELAPSED is not a resolution. False-resolve and false-not-yet are conditional on the hidden end-of-episode truth, so a dash in the table means that type had nobody on that side of the truth.
7. **Slow truth.** Active until `ours` completes a second intervention, then inactive. Naive and 4-check never start that second intervention, so every slow learner stays active under those two policies and false-not-yet is undefined for them.
8. **Forgetful truth** is the coin flip (0.6) rolled once per learner, shared across policies. It changes answers only on the ghost. End-of-episode truth uses the flip even if the policy never asked the ghost, which is why naive's false-resolve on this type is 1.
9. **E14 truth is not written into the engine.** Non-STABLE classes start UNSEEN at `EXAM_DSA_PRIOR` / `POPULATION_PRIOR`. STABLE main classes are drawn only from classes that are truly inactive. No planet bonus.
10. **Coding responses.** For each active class on the item, `e_ik_sim` is the authored exposure times a ±50% draw, clipped to [0, 1]. P(pass) = `(1 - max e_ik_sim) * skill`. A failure picks a class proportional to `e_ik_sim`, then the E1 confusion renames it. CORRECT or OTHER leaves the failure with no signature. The engine update still uses the authored exposure. Trace: if an active class sits in the belief map, the belief option (wrong) is given with `p_b_sim` uniform on [0.4, 0.9]; otherwise correct with probability `1 - slip`, slip being `SLIP` times ±50%.
11. **Found** means `P(A) ≥ DIAGNOSIS_ACTIVE_P` (0.5). Profile F1 is the set F1 of that indicator against the hidden active set, per learner, then averaged. Empty versus empty is 1. Brier is the mean squared error over the 17 classes.
12. **Items to first true finding** ignores learners with no active class. A learner who is never found counts as 10. If a policy stops before 10 items, the F1 curve holds the last value. In this run all three policies administered 10 items (mean items 10).
13. **Random** uses `ml.exam.select._allowed`, which is not in the public export, so the 5+5 quotas, sector cap, no-consecutive-sector rule, and coverage rule match the engine. The pick among the legal items is uniform. `run_exam` returns only the report, so the per-item curve is driven here with the same update functions rather than through `run_exam`.
14. **Fixed arm** plays `fixed_blueprint(strings=True)` in order. Tie-breaks on the adaptive arm use `learner_id = sim-{index}` and `exam_id` equal to the policy name.
