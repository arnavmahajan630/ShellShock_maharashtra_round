## Decisions where §10 gives no number

- Operator drop rate is not stored. Attempts are site counts from `find_sites` on allowed correct variants (the generator's loop, no interpreter). Unique unaugmented base rows in the file are a lower bound on kept mutants, because selection can drop some. Luck / attempts is a lower bound on the drop rate; (attempts − unique kept) / attempts is an upper bound. Fail only when the lower bound is above 0.40.
- Near-constant: most common finite value covers at least 99% of finite rows.
- Length separates when KS D ≥ 0.25 and p < 0.01, both samples at least 20. The same-problem KS is extra and does not change the status.
- Stump macro-acc is unweighted mean recall. A non-defining feature also trips the rule when overall accuracy is above 0.60.
- Predicate means use only group-A members of `CLASS_DEFINING_FEATURES`.
- Event "concentrate" means at least half of the rows that carry the event.
- Projection fails only when silhouette on unique train hashes is at least 0.20.
- Exposure gap uses a 1e-9 tolerance so a gap of 0.3 is not over the bar.
- 10.7 uses a binary LightGBM on groups A and C only (100 rounds, `min_data_in_leaf` 5, 2 threads, no early stopping). Folds are `StratifiedGroupKFold` on `problem_id` (5 folds). The interval is a 1,000-draw group bootstrap of the out-of-fold AUC. The section status follows the R-llm point AUC. ITSP is the same bar, reported beside it. ITSP problem ids are not in the bank, so group C comes from the first non-`main` function signature in the code. Class labels on both external files are dropped before the model is fit. R-llm is 58 rows, 25 problems, 3 AST parse failures, and every problem id is in the bank. ITSP families: lab4 88, lab5 48, lab3 46, lab6 43, lab7 41, lab9 33, lab11 28, lab12 27, lab10 25, lab8 17. Top ITSP gain: `a_n_loops` 15.4%, `a_decl_noinit_read_first` 14.3%, `a_return_const_only` 8.6%, `t_has_array_param` 7.2%, `a_printf_in_nonvoid` 6.4%.
