# C2 — DSA operators and predicates

## Built

- `ml/generate/ops_dsa.py`: 20 operators. Five DSA surfaces of main classes (`amb_pair_bound`, `m08_mirror`, `m01_half_bound`, `m02_pointer_stuck`, `m10_print_bool`) and D01–D08 (`d01_else_return` through `d08_array_eq`). D08 is last in `all_ops()`.
- `ml/generate/predicates_dsa.py`: `holds(op_id, code)` is the static half of 03 §3.5.4. It does not look at traces.
- `tests/C2/test_ops_dsa.py`.

A site is an int index into `sites(op, code)`. `apply` parses again, edits that site, and reprints the whole function with `pycparser.c_generator.CGenerator`. `amb_pair_bound.labels` is `("M01", "M08")`. Nothing here is `test_only`.

`pytest tests/C2` with `.venv\Scripts\python`: 5 passed.

## Where the bank has no site

| Operator | What is missing |
|---|---|
| `d08_array_eq` | No variant compares two different arrays. Q15 compares `s` with itself. Covered by a hand-written `same_text(char s[], char t[])` in the test. The mutant is `if (s == t) return 1; else return 0;`, which fails the equal-text test because the interpreter compares addresses. |
| `d05_unreachable_base` | No site on Q16. Every variant steps with `n / 10`, not `n - 1`. Q17 and Q18 have the site. |
| `d06_grow_arg` | No site on Q16, same reason. Q17 and Q18 do (`f(n - 1)` → `f(n + 1)`). |
| `d07_discard` | No site on cv3 of Q16, Q17 and Q18. Those assign the call to `rest` and combine afterwards. cv1 and cv2 are the `return n * f(...)` / `return n % 10 + f(...)` shape and do fail a test. |
| `d01_else_flag_reset` | Only Q04 (`found = 1`). Q08 cv3 sets `ok = 0` on a bad pair, which is not that shape. Q08 cv1/cv2 are `d01_else_return`. |
| `m10_print_bool` | No site on Q08 cv3 (`return ok`, not `return 0` / `return 1`). |
| `amb_pair_bound` | No site on Q08 cv3 (`a[i - 1]`, bound already `i < n`) or Q11 cv3 (the shift is `a[i - 1] = a[i]`). |
| `m08_mirror`, `m01_half_bound` | No site on the two-pointer variants (Q10 cv2, Q15 cv2). The `n / 2` and `a[n - 1 - i]` variants have sites. |

`amb_pair_bound` does find a site on Q11 cv1 and cv2 (`i < n - 1` with `a[i + 1]`), but the mutant still passes: the extra iteration writes `a[n - 1]` and the saved `first` overwrites it. Q06 and Q08 cv1/cv2 fail, so the operator is kept. C3 should expect those Q11 rows in the passes-by-luck pool.

## Decisions

1. **`m01_half_bound` emits `i < n`, not `i <= n / 2`.** One site, one edit. `i < n` is the reverse-twice form (`r_eq_reversed_twice`).
2. **`m02_pointer_stuck` also deletes `i = i + 1` and `j = j - 1`.** Q12 cv3 is written that way. The loop test must be `i < j` and both names must be used as array indexes, so a search `i < n` is not a site.
3. **`d02_*` keys off the variable that is initialised with `/ 2`,** not the spelling `low` / `high`. Q05's `lo` / `hi` / `mid` match.
4. **`d05_unreachable_base` is one edit:** base condition becomes `n == 0`, and every self-call argument `n - 1` becomes `n - 2`. The operator does not see the tests. Every bank site is on Q17 or Q18, and both have an odd `n`, so the §3.5.1 keep rule ("only if some test has odd n") holds for every row C3 can build. Q16 has odd `n` too, but no `n - 1` step, so there is nothing to keep or drop there.
5. **`holds` for D05 is the class check, not only the deleted-if sentence.** Drop-base has no base `if`. The unreachable mutant still has `if (n == 0)`, so `holds` is also true when every base condition is `== 0` and a self-call steps by `n - 2`. Correct `n == 0` with `n - 1` (factorial cv2, sum_digits cv2) stays false.
6. **`holds` for D03 is cross-assignment or an unsaved rotate.** `a[i] = a[j]; a[j] = a[i]` covers `d03_drop_temp`. `d03_rotate_no_save` is a shift plus `a[…] = a[0]` with no `int first = a[0]` left. Correct rotate still saves `a[0]`, so it does not fire.
7. **`holds` for D04 is `i < 1` on a loop that still contains an inner loop, or a frozen `i = 0` plus an array move and no nested loop.** A correct `while (i < n)` that updates `i` does not fire. Neither does a correct nested sort.
8. **D01–D08 `holds` is shared by both operators of the class** (else-return or else-flag, `low = mid` or `high = mid`, and so on). The five surface operators have their own checks so a correct variant does not look like the mutant. `holds` is false on every correct variant in `ml/problems/dsa`.
